# Step36最小计划与停止边界

1. 保留Step35C整个冻结节点/VM/Store补丁和35B同一个native so，勿仅换二进制不记录依赖/库hash。
2. 准备一个隔离节点、同一账本种子和WASM、同一个同步SDK客户端。先G0/G1各少量功能Smoke，核对Gas、结果、读写集、事件及提交查询，再决定开始有限端到端配对。不得直接扩大成四节点或并发。
3. E2E仍统一SDK开始→同步响应返回，VM时间另记录。响应延迟、日志等效TPS、提交TPS分别统计；不把本轮排空时间当性能收益。
4. 每轮确认HTTP、Core、账本写入、WAL、归档和Owner任务结束后停止节点；保留原1536MiB保护。少量配对后资源检查，样本量根据运行余量限制，不为凑数提高阈值。
5. 异步业务、Quick模式、主动归档、MessageBus普适排空和故障恢复作为后续独立问题，不混入当前有限准入。重启查询不等于断电耐久认证。

本轮停止于生命周期修复与准入结论，不启动正式E2E，不制作PPT，不推送远程。
